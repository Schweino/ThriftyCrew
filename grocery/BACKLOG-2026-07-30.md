# Grocery backlog after the 2026-07-29 audit

Every item traces to `AUDIT-2026-07-29-findings.txt` (85 raw findings) or `AUDIT-2026-07-29-synthesis.md`
(57 confirmed, deduped to 45), or to something that broke during the 2026-07-29 run itself.

**Model labels.** FABLE = accuracy-critical logic, a design decision, or long unattended autonomy where a
wrong answer is expensive and hard to spot. OPUS = well-specified mechanical edit where the shape is already
known and the risk is low. When in doubt on anything that decides a published PRICE, use Fable.

## TIER 1 - shopper-visible or structurally blind

### 1. Guard 11 has no independent source to check against  **FABLE**
Guard 11 now announces its own blindness (good), but Baker's - the largest store on the board - still has
ZERO independent price verification. Guard 10 only compares two of our own numbers, so the milk-bug class
(a `current_price` COMPUTED wrong) ships unseen.
**BLOCKED ON A PREREQUISITE, found 2026-07-29:** the audit proposed repointing it at "the raw Kroger capture
audit-basis-reconcile reads via -RawDir". That capture does not exist. `pull-regular-bakers-api.ps1` persists
only the finished `bakers-regular-<date>.json` (:517) and a refusals file (:452); `out\kroger-api-eval` holds
one quarantined file from 07-24. Repointing the guard at `current_price` on the same row would duplicate
guard 10 exactly - a guard that looks alive and proves nothing.
**Do:** make the puller persist the raw API response per item (product_id + price.regular + price.promo +
netWeight) to `out\bakers\raw-<date>.json`, THEN rewrite guard 11 to join on product_id against it. Ship the
guard advisory for one run before making it hard-fail.

### 2. Sam's derived-size fallback publishes back-solved package sizes  **FABLE** (decision + code)
`build-sams-deals.ps1:30-35` back-solves the pack size from Sam's own posted unit price when no reading of
the name reconciles. Sazon published at $0.07/oz against a true $0.727/oz, 8x under the next store, and it
crowned the row. 62 of 2,537 rows used the fallback today; 3 won crowns.
It is DOCUMENTED AND SELF-TESTED as intentional - right for the Q-tips/trash-bag bulk class, catastrophic for
a store-side dropped decimal. **This is a judgement call, not a bug to patch.** Either reject when the name
states a quantity in the unit Sam's priced by and no reading reproduces it, or add a cross-store plausibility
rail on crowns. Needs a frozen must-fire fixture for the Goya row either way.

### 3. Family Fare's live pull is thrown away every day  **OPUS**
`out\throttled\family-fare-<date>.throttled.json` holds 773 rows pulled this morning; compare-deals reads
`out\regular\` only. 705 rows confirm the board, **32 disagree, 5 are published cells** (sour cream, lemons,
strawberries, chipotle-adobo, zucchini). 13 consecutive throttled days; 225 of 256 FF cells are 11-16 days old
and 20 are past the file's own 14-day cap.
**Do:** feed throttled captures through the same carry-forward union Walmart uses. A throttled pull is a
PARTIAL pull, not a bad one. Also measure the carry cap against publish date, not capture date.

### 4. The recipe board contradicts the staples board on the same page  **FABLE** (decision)
`out\recipe-board.json` is a frozen 2026-07-12 snapshot supplying 807 of 3,471 priced chips, with NO Fareway
row anywhere. On 124 same-store same-unit cells the two halves disagree by >=10% (Family Fare ground coriander
$3.21/oz vs $1.05/oz on one page). Also the source of 5 wrong-unit record lows (per-oz banked under pound-unit
commodities).
**Decide:** rebuild it through the weekly pipeline, drop the 78 overlapping ids and let the fresh row own them,
or keep it frozen and accept two prices for the same jar.

### 5. Six Walmart terms owe a retry  **OPUS**
Transient blocks during the 2026-07-29 sweep: 80/20 ground beef, pork chops, potato chips, crushed red pepper,
toilet paper, cheese crackers. One `browser_batch` call using the method in `grocery-browser-exfil.md`.

## TIER 3 - correctness debt that will bite

### 14. Verdict persistence - the highest-leverage change in the rules layer  **FABLE**
39 of today's live drops can NEVER be expressed as a rule (the token also appears on something we keep, or the
item name IS the commodity's own words), so rules alone will never converge and the same judgements are re-made
every week. Write `verdict-suppressions.json` keyed on (commodity, store, normalised item), apply it in
verify-apply every week regardless of which week produced it, and write the judged `item` into the verdict file
so promote-verdicts stops inferring it.

### 15. Three copies of the size parser, diverging in BOTH directions  **FABLE**
`compare-deals.ps1:166` has no weight-first pack (`16 oz 6 pk`) and no `x` separator (`12 x 12 fl oz`);
`pu-lib.ps1:60` cannot cross a hyphen (`6-pack 12 fl oz`); `build-walmart-deals.ps1:118` never got the
leading-dot decimal fix (`.98 oz`). Each is latent alone. Do them as ONE unification pass with fixtures - and
note the scout's warning that routing Get-SizeAmount through Get-LinkPerUnit is WRONG (they diverge on 76 real
size strings in both directions).

### 16. Four batch importers still read captures as ANSI  **OPUS**
`import-browser-batch`, `import-walmart-batch`, `import-instacart-batch`, `import-aldi-batch` all use a bare
`Get-Content`. The next staples expansion re-introduces today's mojibake; for Walmart it corrupts the PRICE
field too (the cent glyph). Dot-source capture-lib and read `-Encoding UTF8`.

### 17. Seven commodity rules contain mojibake instead of accented letters  **OPUS**
`jalape[nÃ±]os?` matches neither a real n-tilde nor the mojibake pair, and butternut-squash/pie-pumpkins can no
longer exclude "puree". Now that ingest repairs names, correctly accented text is flowing again. Rewrite as
`[nñ]` / `[eé]` and add a guard that fails when any commodities.json pattern contains U+00C3/U+00C2/U+00E2.

### 18. The daily job still banks the raw pre-verify board  **OPUS**
`check-ad-cycles.ps1:263` runs update-history against the unverified board - the exact bug fixed in the weekly
path on 2026-07-29. SKILL.md also still instructs the raw update-history in two places.

### 19. `import-walmart-batch` is a second Walmart writer with independent size math  **FABLE**
Writes into the same `walmart-regular-<date>.json` with none of build-walmart-deals' invariants: no
engine-reproduces-the-unit-price check, no multipack pre-filter, a third independent cents rule. 23 such rows

### 20. 16 remaining implausible record lows / 8 poisoned entries  **OPUS**
